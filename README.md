## 🌟 Overview

SpendPulse is a zero-dependency, dual-themed personal finance and expense analytics web application. Built natively with semantic HTML5, modern Tailwind CSS, Chart.js, and vanilla ES6+ JavaScript, it offers a seamless and responsive experience right out of the box—no complex build steps required.

## ⚡ Key Features

- **🎨 Dynamic Theming**: Premium Light Mode and Dark Mode environments featuring frosted glassmorphism that are fully reactive and instantly swappable.
- **📊 Visual Analytics**: Interactive Category Distribution Doughnut chart and a dynamic 6-Month Income vs. Expense Trend bar chart powered by Chart.js.
- **🌍 Settings & Localization**: Real-time currency switching (USD $ / INR ₹) applied seamlessly across all rendering, ledger views, and charting tools.
- **💾 Data Portability**: Perform full CSV exports for analytical tools (Excel, Google Sheets) or secure your data with total JSON encrypted backup and restoration.
- **🗑️ Safe State & Soft Delete**: Never lose data abruptly. A built-in "Trash" retention mechanism holds onto deleted transactions for 3 days before initiating permanent automated clearance.
- **🔒 Secure Client-Side Storage**: Complete `localStorage` persistence reliably retains your user settings, ledger transactions, and trash data solely within your local browser sandbox.
- **♿ SEO & Accessibility**: Fully integrated semantic architecture (`<header>`, `<main>`, `<dialog>`), Open Graph tags, and comprehensive keyboard-focus outlines for power accessibility.

## �️ Local Development & Setup

SpendPulse uses a robust **zero-build architecture**, making it effortless to run and inspect. It executes natively in any modern browser without relying on Node modules or task runners.

To experiment with the project locally, serve the root directory over any standard HTTP connection:

```bash
# Clone the repository
git clone https://github.com/Ankan-76/expense-tracker.git
cd expense-tracker

# Using Python 3
python -m http.server 8080

# Or using Node's npx serve
npx serve .
```

After serving, navigate to `http://localhost:8080` in your web browser to interact with the dashboard.
